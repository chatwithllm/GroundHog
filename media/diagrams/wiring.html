RTK Rover — Complete Wiring

Every pin connection, one net at a time. This build uses the LC29H as a Pi HAT: the GPS lives on the Raspberry Pi, and the Pi forwards the fix to the F405 over USB (MAVLink). Power off while wiring; check polarity on the 24V.

Step 0 / 8
  • 1. 24V power 24V
    Battery PWR+ → each motor Red (+24V) • Battery PWR+ → UBEC IN+ • Battery PWR− → motor Black (GND) & UBEC IN−. Motors are BLDC5520 24V with an integrated driver — no external motor driver. ⚠ Check +/− twice before power-up.
  • 2. 5V logic 5V
    UBEC 5V → F405 5V and Pi 5V • UBEC GND → each GND. The LC29H HAT is powered by the Pi through the header.
  • 3. Common ground GND
    Tie ALL grounds: Battery− = motor Black = F405 GND = Pi GND = UBEC−.
  • 4. Motor PWM + DIR PWM+DIR
    F405 PWM out → each motor Blue (speed) • F405 relay/GPIO → each motor Yellow (DIR/direction) • common GND. (SERVO1=ThrottleLeft, SERVO3=ThrottleRight, MOT_PWM_TYPE=3 Brushed-With-Relay.)
  • 5. Motor 5-wire connector 5-WIRE
    Each motor gets 5 wires: Red +24V, Black GND, Blue PWM (speed), Yellow DIR (direction), Green FG (tacho). The integrated driver runs off the 24V rail — never off 5V. (Flip the DIR line to reverse that wheel.)
  • 6. GPS / RTK (on the Pi) GPS/RTK
    LC29H RTK HAT seats on the Pi’s 40-pin header (Pi UART, e.g. /dev/ttyAMA0 or /dev/serial0). Attach the antenna. The Pi runs the NTRIP client and injects RTCM straight into the LC29H → centimeter fix. No GPS wire to the F405.
  • 7. Pi ↔ F405 bridge MAVLink
    Pi USB ↔ F405 USB (MAVLink). The Pi forwards the GPS fix to the F405 as GPS_INPUT — set ArduRover GPS_TYPE = MAV. Same link carries missions/telemetry.
  • 8. Motor FG feedback FG
    Each motor's Green FG (tacho out) → F405 — one pulse train per rev gives wheel speed. FG replaces the old wheel encoders. (Confirm the FG signal is 3.3V-safe.)
