The journey

From locked chip to a plan

Read-lock crackedsolved

Mass-erased the RDP-protected GD32F103 clone; flash writable again.

Our own firmware runssolved

Bare-metal build: PWM, ADC, GPIO, bit-bang I²C, UART console — full control.

24V confirmed livesolved

Metered 24.1V on the board — the pack delivers power; no BMS handshake needed.

Stock motor rail gatedblocked

24V present but switched off before the motor drivers — the stock MCU never powered them.

Motors are BLDC — drive directdecision

Label reads BLDC5520 24V: driver built into each motor. No brushed driver needed — feed 24V + PWM + DIR; the FG wire returns speed.

Bench spin via ESP32 → then F405next

Prove one motor on an ESP32 (PWM + DIR + FG), then F405 ArduRover brushed-with-relay ×2 + RTK.

Pi = companion (RTK corrections, GPS, missions). F405 = real-time brain: PWM speed + DIR into each motor's built-in BLDC driver, fuses GPS + IMU + FG wheel-speed. No external motor driver — the motors drive themselves. One salvaged 24V pack, common ground.
